# Release 1.4.1

**Date:** 2026-10-23
**Previous:** v1.4.0

## Highlights

Updates the bundled opt-in library to 1.3.3, which fixes an opt-in notice that couldn't be dismissed. It also stops builds from bundling an Action Scheduler that needs a newer WordPress than FSS supports.

## What's New

### Fixes
- The opt-in notice can be dismissed, and it links to the opt-in screen with accurate wording.
- Opening the scanner settings shows the opt-in screen again until Allow or Skip, if it was left without a choice.
- On sites running other Fullworks free plugins, the opt-in notice and menu belong to the right plugin.
- Deleting the plugin also removes its opt-in setting (`FSS_form_rendered`).
- Action Scheduler is held at 4.1.x, matching the WordPress 6.8 minimum. An unpinned build would have taken 4.2.0, which needs 6.9.

### Improvements
- Bundled opt-in library updated to 1.3.3.

## Breaking Changes

None. The minimum WordPress version stays 6.8.

## Migration Guide

None. Stored opt-in choices and dismissals are kept.
